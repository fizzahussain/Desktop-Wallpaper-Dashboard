# Desktop Mode

The dashboard is designed to behave like a desktop layer rather than a normal application window.

- Borderless and fullscreen
- Hidden from the taskbar
- Always-on-bottom with the Windows `screen-saver` level
- Starts automatically with Windows when packaged
- `Ctrl + Shift + Q` exits the app
- Wallpaper and dashboard state remain local to the machine

The Electron window configuration lives in `src/main.js`.
